# Проверка облаков — 26 сентября 2026

Требования: бесплатно, без банковской карты, без домашнего компьютера,
с удалением рабочих медиа и без платных API. Ни один из проверенных вариантов
не даёт подтверждённой гарантии обработки произвольных видео любого размера.

| Вариант | Что подтверждено первоисточником | Вывод |
|---|---|---|
| [blitz.cloud](https://blitz.cloud/docs/limits/) | Бесплатный план без карты; фоновые боты без адреса не засыпают; Docker-контейнер small до 512 МБ, до 0.5 CPU, гарантировано лишь 0.05 CPU; публичная бета | Наиболее интересен для пилота; скорость, диск, перезапуски и Bot API требуют живой проверки |
| [Render Free](https://render.com/docs/free) | Бесплатный web service; сон после 15 минут без входящих запросов; исчезающий при рестарте диск | Запасной webhook-вариант; обычный Bot API ограничивает вход 20 МБ |
| [Hugging Face](https://huggingface.co/docs/hub/spaces-overview) | Создание обычных Docker/Gradio Spaces требует платного плана | Ранее распространённая рекомендация бесплатного CPU Docker для нового аккаунта больше не подходит |

## blitz.cloud: что ещё нужно проверить

- [Официальный режим background](https://blitz.cloud/docs/deploy-from-github/#bots-and-background-workers)
  работает без публичного адреса и без искусственных keep-alive запросов.
- [Политика размещения](https://blitz.cloud/eu-data/): инфраструктура ЕС, провайдер
  инфраструктуры технически имеет доступ к хранимым данным. Это не сервис с
  доказанной гарантией zero retention. Удаление файлов нашим кодом не равно
  гарантированному физическому стиранию всех следов у хостинга.
- [Состояние платформы](https://blitz.cloud/whats-live/) указывает публичную бету,
  отсутствие бэкапа файлов приложений и пока только публичные исходники/образы.
  Публичность кода НЕ требует публикации токена или фотографий.
- Для больших входных файлов нужен отдельный Local Bot API. Его можно запустить
  на облаке, «local» не означает компьютер пользователя. Нужно проверить совместную
  память, временный диск и очистку кеша самого Bot API, не только файлов обработчика.
- 2 ГБ в рекламе — общий пул зарезервированной памяти аккаунта, НЕ 2 ГБ одному боту.
- Нельзя обещать скорость или предел размера, пока не проведён тест на площадке.

## Бесплатные API для улучшения фото

Подтверждённого бесплатного безлимитного API с гарантированным удалением не найдено.
[Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers/pricing)
дают ограниченные кредиты. [Replicate](https://replicate.com/docs/topics/predictions/data-retention)
имеет собственные сроки хранения. Бесплатное демо чужого Space не гарантирует ни
доступность, ни конфиденциальность. Поэтому проект использует открытые веса
Real-ESRGAN внутри собственного контейнера, не отправляя фотографии внешнему AI API.
